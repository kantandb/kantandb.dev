HTTP document API

Work with JSON documents.

Document operations

Named databases and revision checks

The server assigns UUIDv7 IDs and supports document creation, reads, replacement, patches, and deletion. ETags and If-Match reject stale writes.

  • ETags
  • JSON Merge Patch
  • JSON Patch

Request flow

HTTP → Validate → Store

Strict routes, bounded bodies, and consistent JSON errors.

02 / 03

Storage and concurrency

Keep related changes together.

Documents, database metadata, and index entries share a local ordered key-value store. Synchronous batches make related changes atomic and durable. Striped locks coordinate concurrent writes and keep database deletion from racing with them.

One process and one local data directory.

03 / 03

Indexes and queries

Query indexed JSON fields.

Databases define secondary indexes with JSON Pointer paths. Queries support scalar equality and ordered number or string comparisons. Results are paginated, with opaque cursors for indexed queries.

This is an experiment, not a production database.
